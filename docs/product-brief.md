# Product Brief — CareerPilot AI V0.1

## Problem

Professionals moving into AI often receive generic learning roadmaps that ignore their existing experience, available time, evidence of skill, and target role. General-purpose assistants can generate advice, but they do not by themselves create a controlled, longitudinal career-state product.

## V0.1 user

An experienced professional who wants to transition toward one of four AI role families:

- AI Product Manager
- GenAI Engineer
- AI Engineer
- AI Solution Architect

## Job to be done

> Given my current experience, AI exposure, target role, time budget, and constraints, assess what I can reuse, identify the gaps that matter, tell me whether my timeline is realistic, and give me an evidence-oriented path I can execute.

## V0.1 value proposition

CareerPilot does not treat learning completion as competence. It recommends a pathway plus the evidence the learner should produce to demonstrate each capability.

## Scope

### In

- structured learner assessment
- target-role blueprint retrieval
- learning-capacity calculation
- tool-using single agent
- gap prioritization
- staged roadmap
- evidence plan
- first-30-day actions

### Out

- live job-market search
- LinkedIn/Naukri integration
- Udemy/course completion integration
- resume parsing
- long-term learner database
- multi-agent architecture

## Success criteria

A successful V0.1 run should:

1. use the target-role blueprint rather than inventing role requirements;
2. use deterministic capacity calculation rather than mental arithmetic;
3. reuse relevant prior experience;
4. identify prioritized gaps rather than a generic syllabus;
5. produce evidence requirements, not just course recommendations;
6. return a machine-readable roadmap that the UI can render predictably.
